# A0 dataset and tokenizer record

Status: **prepared; training remains hardware-gated**.

The A0 preparation uses the `roneneldan/TinyStories` dataset at immutable
Hugging Face revision
`f54c09fd23315a6f9c86f9dc80f725de7d8f9c64`. The source card identifies the
dataset as synthetic short stories generated by GPT-3.5 and GPT-4 and reports
the license as `cdla-sharing-1.0`. The research paper is recorded alongside
the source metadata. The machine-readable preparation specification is

## Fixed preparation procedure

1. Download the four pinned source-training parquet shards and one pinned
   source-validation parquet shard at the revision above.
2. Read only the `text` column in source file and row order.
3. Strip leading/trailing Unicode whitespace, preserve internal text and case,
   discard null/empty rows, and hash the normalized UTF-8 text with SHA-256.
4. Keep the first occurrence of each text hash. The official source `train`
   split becomes final `train`. Each remaining official source-validation row
   is assigned to final `validation` when the first 32 hash bits are even, and
   final `test` otherwise. This makes the assignment deterministic and prevents
   duplicate text hashes from crossing final splits.
5. Train a 32,000-token byte-level BPE tokenizer on final `train` documents
   only. Special tokens, in fixed ID order, are `<|pad|>`, `<|bos|>`,
   `<|eos|>`, and `<|unk|>`.
6. Encode each document as `BOS + text + EOS`, concatenate documents within
   each final split in source order, and write uint16 little-endian token
   streams. Training/evaluation consumers use non-overlapping complete
   512-token sequences and discard only the recorded tail of each split.

The preparation script is
[`scripts/prepare_tinystories.py`](../scripts/prepare_tinystories.py). It
creates `data/tinystories_a0/manifest.json`, which records raw-shard hashes,
the split-manifest hash, tokenizer hash, token counts, and runtime versions.
It never imports the model or starts training.

Run from the repository root after the data extras are available:

```bash
python3 scripts/prepare_tinystories.py
```

The existing A0 model configuration remains unchanged: vocabulary size 32,000
and 41,866,240 unique trainable parameters.
